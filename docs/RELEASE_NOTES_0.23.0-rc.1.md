# 0.23.0-rc.1 候选版发布说明（草案）

本说明整理相对 `v0.22.0` 的产品变化，供批准候选提交时审阅；文档存在不代表已经推送、创建标签或正式上线。持续更新的使用边界统一见[候选版状态](../plugins/codex-module-governance/references/release-status.md)。

## 对使用者的变化

- **只有一个中央入口**：当前窗口可以成为中央；中央可切换模型，不因换模型另建中央。
- **模型和权限不再锁死**：新任务默认 Terra，可按用户选择更换；续办保留选择。默认原生完全访问，可主动选择原生受限模式，不再依赖自定义权限配置。完全访问不代替业务授权。
- **围绕成果组织任务**：施工大纲与任务对应可验收的成果、阶段和依赖；按项目需要组织，不强制所有项目使用同一种板块结构，也不把每个操作步骤都拆成正式任务。
- **人工纠偏可以延续**：调整方向后重新核对受影响任务和旧派发材料，保留无关批准；外部等待、返工与交付反馈能够关联原任务，保留历史证据。
- **中央交接减少手工搬运**：在原生能力可用并满足交接条件时，串联交接包、同项目建窗、增量核对、唯一接管与打开新中央；没有真实回执不算交接成功。
- **减少重复确认和机械验收**：在已批准范围内接续工作，验收要求与影响相称；高风险业务操作仍按实际授权和证据要求处理。

## 保留的修复与本轮收尾

包含此前新项目启动修复：首次中央身份、保存项目绑定和总账写入身份校验。补齐纠偏后续派、手工备用包项目与模型一致性、旧受限补派兼容及回退前兼容检查。内部中央参考资料移出可见 Skill 目录，历史规则保留替代说明；个人维修工具和真实工程记录不随包分发。

## 安装与兼容

发行候选号为 `0.23.0-rc.1`；本机安装标识的 `+codex...` 是构建标识，内部配置版本仍为 `0.22.1`。本次不改写现有稳定标签 `v0.22.0`。

旧聊天不会热加载全部新规则；已有项目通过受控中央交接接续，不初始化第二中央，不覆盖历史总账与证据。旧备用包保留，新导出按当前合同生成。回退前必须备份并检查全部真实私有数据根的兼容性，不以卸载重装或删除数据代替检查。操作步骤见[安装说明](INSTALLATION.md)及[版本与发布规则](VERSIONING_AND_RELEASE.md)。
