# C11 外部 Skill 登记与适配

Boss 不需要现在就把所有 Skill 找齐。系统先固定“这个岗位需要什么能力、输入什么、输出什么、缺失时怎么办”，以后找到合适 Skill 再登记。

每个候选必须记录来源、固定版本或 commit、许可证证据、权限、替代关系和降级方案。核心能力缺失会阻断依赖任务；可选能力缺失只关闭对应功能，不影响其他模块。

更换 Skill 不会改变中央任务、状态、证据和 Boss 授权协议。同一能力槽同一时间只有一个默认 Skill。C11 不自动安装或调用；实际安装仍需 Boss 批准并在 C13 干净环境验收。

验收运行 `./scripts/verify-c11.sh`，应覆盖许可证、版本锁、权限、核心缺失、可选降级、显式替换、协议不变、幂等和防篡改。
