## 验收结论

| 验收点 | 结果 |
|---|---|
| 不建第二套状态 | C07 复用 C03，原任务状态全过程不变。 |
| 顾问不替 Boss | 顾问只能推荐、要补证或无安全建议；不能生成窗口回传包。 |
| Boss 决定回原窗口 | 回传包绑定原任务和原窗口，不能选择请求外方案。 |

| 幂等与防篡改 | 重复输入不重复写入，改动请求或回执后完整性检查失败。 |
