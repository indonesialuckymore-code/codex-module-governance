# 已确认的架构决定

| 编号 | 决定 | 当前影响 |
|---|---|---|
| ADR-001 | Boss + 唯一获授权总设计师负责整个项目设计；总设计师可以是 Fable、C00 或 Boss 指定的其他规划方。 | Codex 中央不另立全局计划，只接管冻结大纲中明确归属 Codex 的施工范围。 |
| ADR-002 | Codex 中央默认 Sol，任务窗口与一级子 Agent 默认 Terra。 | 配置样例和后续任务包按此默认。 |
| ADR-003 | 一级子 Agent 默认最多 3 个，只允许一级。 | C10 必须按此验收。 |
| ADR-004 | GitHub 产品第一版为私有，许可证为 All rights reserved。 | 不创建公开发布流程。 |
| ADR-005 | 当前没有原生对象级写前硬拦。 | C05/C10 不能以规则文本冒充硬拦。 |
| ADR-006 | Codex 可程序化新建逻辑任务/线程；物理新窗口不作保证。 | C12 保留可复制任务包降级方案。 |
| ADR-007 | 跨模块详细总账不共享；Boss + Fable 5 只维护全局路线与交接摘要。 | C03 只建立 Codex 详细账本；Claude 另有自己的详细账本，双方不共写。 |
| ADR-008 | C02 的项目启动卡和项目索引仅用于私有建档与重复检查，不是工程总账。 | C02 不记录任务、窗口、证据、对象占用或跨模块状态；不得拿它替代 C03。 |
| ADR-009 | C03 唯一详细写入者是 `codex-module-central`；Fable、Claude 中央、任务窗口与子 Agent 只能读取或通过交接引用间接回传。 | 避免双中央处理器和多个详细任务状态源；重复完成信号不重复推进。 |
| ADR-010 | C04 只从 C03 的 `PLANNED` 任务生成待审任务包；任务包不是派发。 | C04 不改变任务状态、不建窗口、不占用对象；Boss 审阅后仍须通过 C05 才可能派发。 |
| ADR-011 | C05 复用 C03 唯一占用分区，采用整包原子预留。 | 任一对象冲突时不做部分占用；后启动任务进入 `BLOCKED` 并硬停，安全任务进入 `READY`，但均不实际派发。 |
| ADR-012 | 跨模块冲突只接收 Fable 交接引用与明确结论，不复制 Claude 细账。 | 保持双模块各自细账，避免形成第三套详细任务中心。 |
| ADR-013 | C06 是 C03 唯一允许写入 `DONE` 的路径，且采用“中央独立验收 + Boss 最终批准”两段式。 | 任务窗口自报完成、中央验证通过或 Boss 单独批准均不能独自形成 `DONE`。 |
| ADR-014 | C06 不释放 C05 占用。 | 避免完成与释放绑死导致失联或恢复时重复施工；占用释放统一留给 C08。 |
| ADR-015 | C07 顾问意见只返回 Boss；Boss 决定后才生成原任务窗口回传包。 | 顾问不能替 Boss 裁定，C07 不修改任务状态、不恢复任务且不自动施工。 |
| ADR-016 | C08 失联先冻结，非 C08 总账写入机械拒绝；新中央接管不恢复业务施工。 | 防止失联时重复派工、完成信号重复处理或占用被提前释放。 |
| ADR-017 | 占用释放与恢复决定分离。 | `DONE` 必须绑定 C06 最终批准；取消任务必须确认回滚和零未完成写入，并另有 Boss 释放授权。 |
| ADR-018 | `central-construction-controller` 是唯一中央 Skill；仓库副本是产品源，本机安装副本只是同一身份的运行镜像。 | C09 启动时验证唯一中央和 C02–C11 执行能力及 C12 前台合同，不产生第二套中央状态。 |
| ADR-019 | C09 的确定性检查脚本只生成路由决定；唯一中央 Skill 可以在既有启动图授权内连续调用下游能力。 | 脚本本身不改总账、不派发、不触碰业务系统；中央自动续派仍必须逐项经过 C04/C05/C10。 |
| ADR-020 | C10 完成前，真实开任务窗口、派一级子 Agent和恢复业务施工都必须硬拦。 | 这是 C09 阶段的历史门禁；C10 完成后由 ADR-021 的两段式确认替代，业务恢复仍受 C08 控制。 |
| ADR-021 | C10 使用“准备派发单→运行时创建/发送→真实 ID 确认”两段式调度。 | 运行时部分失败不更新总账，避免把计划或失败调用写成已派发。 |
| ADR-022 | 绿灯为共享只读，黄灯为 C05 已隔离写入，红灯为冲突或状态不明。 | 绿黄可进入 Boss 批准后的调度，红灯机械拒绝。 |
| ADR-023 | 子 Agent 只向父任务窗口回传，最多 3 个一级，不能宣布 `DONE`。 | 父窗口统一汇总后仍须 C06 独立验收和 Boss 最终批准。 |
| ADR-024 | 外部 Skill 只通过私有能力槽登记，不占用 8 个核心岗位。 | C03 只保存获批引用；详细来源、版本、许可证、权限、替代和降级归 C11。 |
| ADR-025 | 外部 Skill 统一适配到 `codex-governance-protocol-v1`。 | 更换 Skill 不得改变中央任务、状态、证据和授权协议。 |
| ADR-026 | C11 不自动安装或调用外部 Skill。 | 许可证或权限不清时硬停；实际安装及干净环境验收留给 C13。 |
| ADR-027 | GitHub 分发使用项目专用 Marketplace `qianyi-codex-governance`。 | 避免覆盖用户已有 `personal` Marketplace；私有仓库访问权仍由 GitHub 控制。 |
| ADR-028 | 程序安装/升级只替换插件目录，用户数据必须位于仓库和插件目录之外。 | 允许失败保全和程序回退，不覆盖工程总账、证据或业务资料。 |
| ADR-029 | 自动建窗不可用时只输出可复制任务包。 | 不伪造运行 ID、不把任务推进为 `IN_PROGRESS`；人工建窗后仍须 C10 第二阶段确认。 |
| ADR-027 | C12 是无状态自然语言前台，不是第二个中央。 | C12 只把 Boss 口语转换为 C09 标准请求；C09 仍是唯一中央，C03 仍是唯一详细状态源。 |
| ADR-028 | 自然语言批准必须唯一绑定当前项目和治理对象。 | 单独“批准”、多动作、多个候选或只看/执行冲突时必须追问，不能从旧上下文猜授权。 |
| ADR-029 | C12 只在候选唯一时自动补齐上下文。 | 一个项目或一个候选对象可沿用；多个候选必须由 Boss 选择。 |
| ADR-030 | C00 `construction-outline-planner` 是整个项目总设计师能力；Boss 指定唯一总设计师，同一版本不得由两方同时续编。 | C00 设计全项目但只写大纲草案、冻结版和 `OUTLINE_HANDOFF`；C09/C03 只接管 `CODEX_ONLY` 候选任务，其他模块保留交接引用而不复制细账。 |
| ADR-031 | C09 首次运营采用一份中央启动图集中承载任务范围、Boss 决策、依赖和并行波次。 | Boss 对唯一摘要的批准可被图内 C03/C04/C05/C10 复用；C03 仍是唯一详细状态源，范围或风险变化使受影响授权失效。 |
| ADR-032 | C10 新任务必须绑定 Codex 保存项目并回读归属；Git 项目默认标准 worktree。 | 项目 ID、运行环境或目录不符时不得登记 `IN_PROGRESS`；禁止自造目录或 `projectless` 冒充项目任务。 |
| ADR-033 | Git worktree 目录正确但项目 ID 为空时，对同一任务执行项目本地往返交接修复。 | 先交接到保存项目根目录，再交接回原 worktree；最终项目 ID 与目录同时正确才登记，失败不新建平行任务。 |
| ADR-034 | 每个项目只有一个 `CURRENT_CENTRAL` 和一个可选的 `CURRENT_ADJUDICATION`；窗口可换代，逻辑角色不变。 | 任务窗口不再永久绑定某个中央聊天 ID；旧代际只读，新代际读交接包和持久事件箱续接。 |
| ADR-035 | 第一次中央裁定从当前中央复制上下文，后续裁定都留在同一裁定角色；中央只接收裁定影响摘要。 | 裁定讨论不占中央上下文；裁定窗口不能派工、改账、验收或成为第二中央。 |
| ADR-036 | 任务身份由任务 ID 主导，全链唯一标题为 `任务ID｜业务名称`，运行窗口再加 `｜G代际`。 | 总账、任务包、派发单和运行时回读任一不一致都返回 `TASK_IDENTITY_MISMATCH / NEEDS_REVIEW`，不推进 `IN_PROGRESS`。 |
| ADR-037 | 任务经 C06 + Boss 合法写入 `DONE` 后，C06 生成不可变续派触发；中央自动放行原启动图内所有新近合格任务。 | 不再向 Boss 询问是否继续；授权变化、依赖变化、风险升级或 `UNKNOWN/CONFLICT` 只阻断受影响任务并重新请 Boss 决定。 |
| ADR-038 | 窗口身份与任务承接分离；每个窗口终身最多承接两项任务且严格串行。 | 第 1 项完成后窗口可复用一次，第 2 项完成后 `RETIRED`；C03 保存承接历史，C05/C10 拒绝第 3 项。 |
| ADR-039 | 新开还是复用由中央判断，不作为 Boss 逐次决策。 | 中央按项目归属、上下文兼容、材料增量、对象范围和残留风险判断；无法证明安全时新开 Terra 窗口。 |
| ADR-040 | 子 Agent 是任务窗口的弹性执行资源，不是第二任务中枢；提速必须由结构化回传、父窗口质量闸门和 C06 独立验收共同约束。 | 任务窗口在三个固定检查点可按真实独立工作量使用 0–3 个一级 Terra Agent；只允许原范围、无共享写入风险的运行中补派。父窗口读证、补齐验收覆盖并处理冲突后才能申请 C06，子 Agent 数量不会降低最终质量门槛。 |
| ADR-041 | 施工回传采用 C08 持久票据收件箱；中央只接收摘要，全项目一次只保留一个隔离 C06 验收槽。 | 聊天文字不构成回传；`returnTicketId + TASK_EVENT_QUEUED` 是最低投递证明。Boss 可一次批准范围内自动送验，但 `DONE` 仍须独立验收后由 Boss 最终批准。 |
