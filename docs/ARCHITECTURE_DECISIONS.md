# 已确认的架构决定

| 编号 | 决定 | 当前影响 |
|---|---|---|
| ADR-001 | Boss + Fable 5 是全系统统筹；Codex 中央不另立全局计划。 | 所有核心 Skill 只覆盖 Codex 模块。 |
| ADR-002 | Codex 中央默认 Sol，任务窗口与一级子 Agent 默认 Terra。 | 配置样例和后续任务包按此默认。 |
| ADR-003 | 一级子 Agent 默认最多 3 个，只允许一级。 | C10 必须按此验收。 |
| ADR-004 | GitHub 产品第一版为私有，许可证为 All rights reserved。 | 不创建公开发布流程。 |
| ADR-005 | 当前没有原生对象级写前硬拦。 | C05/C10 不能以规则文本冒充硬拦。 |
| ADR-006 | Codex 可程序化新建逻辑任务/线程；物理新窗口不作保证。 | C12 保留可复制任务包降级方案。 |
| ADR-007 | 跨模块总账归口未决定。 | C03 不得开工；C01 不实现共享总账。 |
| ADR-008 | C02 的项目启动卡和项目索引仅用于私有建档与重复检查，不是工程总账。 | C02 不记录任务、窗口、证据、对象占用或跨模块状态；不得拿它替代 C03。 |
