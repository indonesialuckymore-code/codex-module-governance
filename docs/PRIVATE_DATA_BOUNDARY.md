# 私有数据边界

本仓库是产品代码和空白模板，不是任何项目的工程总账或证据库。

## 可以提交

- 插件 manifest、Skill 模板、schema、校验脚本和说明文档；
- 不含真实数据的配置样例；
- 虚构且标明为示例的演示数据；
- 公开可复用的验收规则。

## 禁止提交

- 客户、员工、订单、财务、审批、付款或生产数据；
- 用户工程总账、任务回执、日志、截图和 TEST ID；
- API key、密码、Cookie、Token、证书和私钥；
- 用户名、家庭目录、本机绝对路径和私人链接；
- 真实业务系统的权限配置或导出文件。

## 用户数据的位置

用户在首次初始化时自行选择私有数据目录。该目录必须位于仓库外，或位于被 `.gitignore` 明确排除的目录中。C02 才会实现初始化器；当前版本不创建用户数据目录。

## C00 施工大纲边界

C00 的通用模板可以提交到产品仓库；真实项目的大纲、来源清单、Boss 决定、文件路径、哈希和中央交接摘要只能保存在用户选定的私有位置。规划窗口不得把真实大纲写入本产品仓库，也不得把敏感内容复制进 `OUTLINE_HANDOFF`；交接只保存去敏摘要和不透明引用。

## C02 目录保护

C02 只接受仓库外且不位于任何 Git 工作树内的私有数据目录。初始化器会拒绝产品仓库本身、产品仓库的父目录/子目录，以及任何 Git 仓库或其子目录。这样项目启动卡不会被误提交到 GitHub。

## C03 总账边界

C03 总账、不可覆盖回执和对象占用只存在同一私有目录中。可以保存任务状态、系统生成编号和不透明引用；不得写入真实业务记录、客户/财务数据、实际证据文件、绝对路径、链接、密钥或 Cookie。GitHub 仓库中只保存 schema、程序和虚构测试数据。

## C04 任务包边界

C04 brief、待审任务包和生成回执只存在同一私有目录中。brief 只能写去敏的任务边界与不透明引用；含绝对路径、真实链接、Cookie、密钥或客户/财务资料会被拒绝。C04 包永远不包含派发授权，也不会创建窗口、子 Agent、对象占用、TEST 或业务写入。

## C05 占用检查边界

C05 请求、决定和回执只存在仓库外私有目录；对象使用不透明 `objectKey`/`conflictKey`，不得保存绝对路径、链接、客户资料、财务数据、Cookie 或密钥。跨模块只保存 Fable 交接引用和 `CLEAR`/`CONFLICT`/`UNKNOWN` 结论，不复制 Claude 细任务。C05 只预留治理占用，不是外部文件、Base、workflow 或服务的原生写前锁。

## C06 回传与验收边界

C06 回传、独立验收、Boss 最终决定及回执只存在仓库外私有目录。`return-inbox` 中的回传票据、投递回执、中央接收回执、单槽验收预留和验收结果同样只存在私有目录；中央界面只读取票据、摘要哈希、状态与验收结果，不读取施工原文。GitHub 仅保存 schema、程序和虚构测试；私有材料只保存去敏摘要及不透明证据、TEST、对象和授权引用，不保存真实业务内容、绝对路径、链接、客户/财务数据、Cookie 或密钥。

## C07 裁定请求边界

C07 阻塞事实、候选方案、顾问意见、Boss 决定、原窗口回传包和回执只存在仓库外私有目录。GitHub 仅保存 schema、程序和虚构测试；顾问意见不进入任务窗口，直到 Boss 形成明确决定。

## C08 失联与恢复边界

C08 失联事件、冻结快照、接管授权、恢复决定、释放授权、任务事件和自动回传投递回执只存在仓库外私有目录。GitHub 只保存 schema、程序和虚构测试；恢复快照只保存治理状态与不透明引用，不保存真实业务证据内容。

## C09/C10 启动图与项目绑定边界

真实中央启动图、Boss 决策、范围化批准摘要和波次清单只保存在仓库外私有目录。为验证 Codex 左栏项目归属，C10 私有派发单和运行确认可以保存本机项目路径、标准 worktree 路径、Codex 项目 ID，以及唯一 local 引导任务和最终 worktree 任务引用；C03 通用总账只保留最终任务引用和绑定方式。权限回执可保存当前任务可写根，但不得向任务窗口暴露中央私有治理目录内容。这些定位信息不得复制进公开任务包、GitHub 仓库或对外回传。GitHub 只保存空白协议和虚构路径测试。
