# 安装说明（C02 阶段）

当前仓库已包含 C02 新项目初始化器。它只能进行私有建档和重复检查，不能派工、创建 TEST 或开展业务施工。

后续 C13 验收时，将提供：

1. 从私有 GitHub 仓库取得源码；
2. 注册本仓库 marketplace；
3. 安装 `codex-module-governance` 插件；
4. 新开 Codex 任务并执行首次初始化；
5. 在用户选择的仓库外私有目录建立项目数据。

## C02 开发预览

1. 把 `config/module-config.example.json` 复制到**仓库外、未被 Git 管理**的私有位置，并填写 `storage.userDataRoot`。
2. 在 Codex 中使用“启动新项目建档”调用；系统先做只读查重。
3. 只有 Boss 明确批准后，才会在该私有目录创建项目启动卡。

项目启动卡不包含任务、窗口、证据或业务数据，也不替代 C03 工程总账。C13 完成前，完整安装流程仍仅用于开发预览，不能作为生产启用步骤。
