## 修改与复用

- C13 是发布验证能力，不新增第二个中央，也不新增平行任务状态。

## 验收门槛

- 从新的临时目录取得仓库、安装全部 11 个 Skill，并运行自然语言入口只读冒烟测试。
- 以旧版 `0.12.0` 安装包升级到 `0.13.0`，验证备份存在，再回退到旧版。
- 人为制造升级包损坏，验证原安装摘要不变。
- 用户私有总账放在插件目录外，升级和回退前后字节不变。
- 官方插件和 11 个 Skill 校验器在临时 Python 虚拟环境运行，不修改系统 Python。
- Codex CLI 从本人私有 GitHub 注册 Marketplace、安装插件、读回版本后再移除测试安装；远端 `main` 再次克隆后复验。
- C01–C13 共 150 项唯一自动测试通过；C10 新增 2 项降级测试，C13 新增 5 项发布测试。
- 第一版稳定安装入口固定为私有 Git tag `v0.13.0`，避免新用户无意跟随 `main` 的后续施工变化。

## 剩余风险

- 私有仓库仅对获得 GitHub 权限的用户可安装；公众用户无法直接下载。
- 安装后必须新开 Codex 任务才加载新版 Skill。
- 自动建窗取决于运行表面是否提供真实任务 API；不可用时只降级为复制包，仍需人工新建任务并回传真实 ID。
- 本产品仍没有业务外部系统的原生对象级写前锁；实际项目必须继续实时核对唯一写入来源。
