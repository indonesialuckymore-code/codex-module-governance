# Core Skills 说明

正式产品 Skill 位于 `plugins/codex-module-governance/skills/`。C01 不创建空壳 Skill 来冒充可用能力。

`central-construction-controller` 已由 C09 升级并纳入产品。仓库副本是发布源，用户级目录里的同名副本是运行镜像，两者属于同一个中央身份，不是两套中央。

`construction-outline-planner` 是 C00 整个项目总设计师窗口能力。同一大纲版本只能有一个获 Boss 授权的总设计师；它规划全项目架构、模块归属和依赖，只输出草案、冻结版和中央交接摘要，不写 C03 总账，也不属于第二个中央。Codex 中央只登记大纲中明确归属 Codex 的候选任务。
