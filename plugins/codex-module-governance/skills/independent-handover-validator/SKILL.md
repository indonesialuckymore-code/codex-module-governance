# 回传与独立验收器

严格分离任务窗口自报完成、中央独立验收和 Boss 最终裁定。只写 Codex 私有治理材料及 C03 总账，不修改业务系统。

## 验收顺序

1. 校验 C03 总账、C04 任务包、C05 占用决定及各自回执。
2. 确认 C03 任务因完成信号处于 `NEEDS_REVIEW`，回传窗口与任务一致。
3. 确认 Boss 已允许任务窗口把本次结果回传中央；没有授权时停止。
4. 独立读回十类证据：改前、改后、正例、反例、幂等、回滚、日志历史、上游、下游、TEST/对象编号。
5. 核对是否越界、出现平行机制、未知写入方、扩大权限、未解释错误、重复数据或阻断性剩余风险。
6. 生成不可覆盖验收决定并记录到 C03。只有全部证据通过时输出 `PASS_PENDING_BOSS_APPROVAL`，任务仍保持 `NEEDS_REVIEW`。
7. Boss 最终批准后，使用同一验收决定完成任务；C06 是唯一可绕过普通 `DONE` 禁止门槛的路径。

## 结论规则

- `PASS_PENDING_BOSS_APPROVAL`：全部独立证据通过，等待 Boss 最终批准。
- `NEEDS_REVIEW`：证据缺失或未独立读回，任务不完成。
- `PARTIAL`：已有失败证据、回滚不可执行、未解释错误或阻断风险。
- `CONFLICT`：范围越界、平行机制、未知写入方、权限扩大或重复数据，登记硬停。

## 永久边界

- 任务窗口和子 Agent 只能提交材料，不能写验收结论或 `DONE`。
- 中央验收通过也不能代替 Boss 最终批准。
- 只保存去敏摘要和不透明证据引用，不保存真实客户、财务、密钥、Cookie、链接或绝对路径。
- 不创建 TEST、不修改业务对象、不启停生产入口、不释放 C05 占用；占用释放与恢复由 C08 负责。
